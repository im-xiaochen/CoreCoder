# R11 关键 spec：MCP 分页完整性

状态：待实现。设计：[R11](../R11_mcp_pagination.md)。测试：[test_r11](../tests/test_r11_mcp_pagination.py)。固定协议版本 2025-06-18。

| ID | Given / When | MUST / Then | 对应测试函数 |
|---|---|---|---|
| R11-S1 | 三页 tools，opaque nextCursor | 原样传 cursor、注册全部工具且最后工具可调用，记录 protocol_version | `test_all_pages_and_opaque_cursor_are_followed` |
| R11-S2 | 单页或无工具 | 正常发现，不额外等待不存在的下一页 | `test_single_and_empty_list_remain_supported` |
| R11-S3 | 重复 cursor/跨页重复名/中途退出/错 tools/不支持版本 | 明确 MCPError，不发布部分表，回收进程 | `test_bad_discovery_fails_atomically_and_reaps_process`（5 种场景） |
| R11-S4 | 服务一直返回不同 cursor | 达 MAX_DISCOVERY_PAGES 报页数限制，有限结束 | `test_distinct_endless_cursors_hit_page_limit` |
| R11-S5 | 每页不超时但整体超 INIT_TIMEOUT | 使用单个全发现 deadline，明确超时而非不断续期 | `test_whole_discovery_uses_one_deadline` |

首请求 `{}`；后续 `{"cursor": <原样值>}`。缺 nextCursor 结束；存在时要求非空 string。每页及整个候选注册表必须验证后才能发布。close 幂等并 wait/reap；服务启动成功不等于工具发现成功。

分页和初始化的依据见 [官方 Tools](https://modelcontextprotocol.io/specification/2025-06-18/server/tools) 与 [官方 Lifecycle](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle)。MAX_DISCOVERY_PAGES=100、工具总量限制、原子发布与重复 cursor 防护是本项目的可靠性策略，不冒充协议强制值。

后续验证：跨服务器名称碰撞、总工具数限制、空页仍带 cursor、错误 cursor 类型、tools capability 缺失、真实服务和列表变更通知。
