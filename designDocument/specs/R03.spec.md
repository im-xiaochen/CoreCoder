# R03 关键 spec：撤销冲突

状态：待实现。设计：[R03](../R03_undo_conflicts.md)。测试：[test_r03](../tests/test_r03_undo_conflicts.py)。数据格式见 [公共契约 §2](../CONTRACTS.md)。

| ID | Given / When | MUST / Then | 对应测试函数 |
|---|---|---|---|
| R03-S1 | before 含 CRLF；agent 写入后未被修改；undo | 精确恢复 before 字节，pending 减一 | `test_unchanged_postimage_can_be_undone` |
| R03-S2 | 已有/新建文件 agent 写后被人工改写；默认 undo | 当前内容不变、条目保留、返回 Conflict 和绝对路径；新建文件不能被删 | `test_external_edit_preserves_file_and_checkpoint`（两种存在状态） |
| R03-S3 | agent 写后被外部删除；默认 undo | 文件保持不存在，条目保留，返回 Conflict | `test_external_delete_is_a_conflict` |
| R03-S4 | 文件有冲突；显式 undo(force=True) | 恢复 before，成功后 pending 减一 | `test_force_undo_is_explicit` |
| R03-S5 | 写入后清内存并重载；随后人工改写 | hash 从持久化恢复，仍拒绝覆盖 | `test_conflict_guard_survives_reload` |

允许默认撤销的充要前提：当前存在标志和 after_exists 一致，且存在时当前 SHA-256 等于 after_sha256。校验和恢复使用同一进程内锁；权限错误按 R04 处理。

旧记录缺 after hash MUST 作为 unknown/legacy 冲突；不能补算当前 hash 获得伪授权。CLI MUST 在执行前展示目标；force 仅对明确选中的操作有效。hash 不是外部进程锁，不作无竞争承诺。

后续验证：legacy 记录、工作区/会话隔离、symlink 替换、真实 CLI force/预览、跨进程竞争。
