# R05 关键 spec：请求预算

状态：待实现。设计：[R05](../R05_context_budget.md)。测试：[test_r05](../tests/test_r05_context_budget.py)。函数及结果字段以 [公共契约 §3](../CONTRACTS.md) 为准。

| ID | Given / When | MUST / Then | 对应测试函数 |
|---|---|---|---|
| R05-S1 | 100k 级单行/中文工具结果；limit=2048 | 大输出原文归档可回读；候选消息有路径；budget_ok=true 且估算+reserve≤limit；链完整 | `test_single_line_output_is_archived_and_fits` |
| R05-S2 | 最近组含六个超大 tool reply；limit=4096 | 不遗漏任何 ID，整组 reply 完整且满足预算 | `test_oversized_last_group_keeps_every_reply_and_fits` |
| R05-S3 | system 或 schemas 固定成本本身超限 | budget_ok=false，reason=context_budget_exceeded，输入 history 不被修改 | `test_fixed_request_cost_can_refuse_without_mutating_history` |
| R05-S4 | 最新用户指令自身超限 | 拒绝发送，原指令保持完整 | `test_latest_user_request_is_never_silently_truncated` |
| R05-S5 | 正常小请求、长 system、显式 reserve | input_tokens 等于完整请求计量函数；reserve 精确保留 | `test_count_includes_system_schemas_and_reserve` |
| R05-S6 | Agent 在不可满足窗口下收到大输入 | 在任何 llm.chat 前抛 ContextBudgetExceeded | `test_agent_refuses_before_sending_an_over_budget_request` |

强不变量：`budget_ok => input_tokens + output_reserve <= limit`。changed 不蕴含 budget_ok；失败可发生在完全没有压缩时。所有摘要调用同样受预算闸门约束。归档不得只保存被裁剪预览，且不得在保存失败后丢原文。

本地启发式计量的保证以 estimated 标识展示；provider 真实 token 上限需独立验证。不能用同一个估算器自校验就声称已完成真实 provider 兼容性验证。

后续验证：切模型更新窗口、artifact 满盘/权限错误、单行分页读取、真实 tokenizer、摘要调用预算、输出采集阶段内存上限。
