# R07 关键 spec：参数验证与消息链完整

状态：待实现。设计：[R07](../R07_tool_validation.md)。测试：[test_r07](../tests/test_r07_tool_validation.py)。字段见 [公共契约 §4](../CONTRACTS.md)。

| ID | Given / When | MUST / Then | 对应测试函数 |
|---|---|---|---|
| R07-S1 | 参数为非对象、缺字段、错类型、内置工具未知字段 | 格式错误 reply；display/pre/permission/post 均不调用；后续可继续 | `test_invalid_arguments_are_replied_before_callbacks`（7 种输入） |
| R07-S2 | 参数 JSON 被截断 | ToolCall 保存 raw_arguments 和 arguments_error，不静默使用 {} | `test_truncated_json_retains_error_and_raw_arguments` |
| R07-S3 | display/pre/permission 抛普通异常 | 文件不写；调用有一次 Error reply；历史链完整 | `test_pre_execution_exceptions_produce_reply_without_write` |
| R07-S4 | 写入成功后 post hook 抛错 | 文件已写；reply 保留 Wrote 结果和 post warning；不谎称未执行 | `test_post_hook_failure_keeps_executed_outcome` |
| R07-S5 | 同 batch 有坏参数、未知工具、合法写入 | 每个 ID 有一次回复；合法独立调用执行；非法项有明确原因 | `test_mixed_batch_and_unknown_tool_are_answered_individually` |
| R07-S6 | JSON Schema 未声明但 Python execute 签名要求参数 | 签名错误在 display/pre/permission 前返回 invalid_arguments，且不触发回调 | `test_python_signature_error_is_before_callbacks` |

消息链不变量：assistant 的每个接受 ID 恰有一次后续 tool reply；在回复完前不追加下一条 user/assistant；没有孤儿 reply。重复或空 ID 必须在 assistant 入 history 前拒绝。

参数 schema 校验先于所有回调。MCP additionalProperties 按远端 schema；execute 签名绑定不能替代 JSON 类型校验。对中断，未开始=cancelled、已执行结果不明=unknown；错误文本不得诱导自动重试未知副作用。

后续验证：重复/空 ID、嵌套 schema/enum/bool 整数区别、worker 异常、Ctrl+C 收尾、非 string 工具返回和结果未知状态。
