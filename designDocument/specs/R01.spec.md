# R01 关键 spec：工具与会话所有权

状态：待实现。设计：[R01](../R01_agent_state_isolation.md)。测试：[test_r01](../tests/test_r01_agent_state_isolation.py)。新增 API 见 [公共契约 §1](../CONTRACTS.md)。

MUST 表示验收硬条件，SHOULD 表示推荐实现。这里描述的是修复后的行为。

| ID | Given / When | MUST / Then | 对应测试函数 |
|---|---|---|---|
| R01-S1 | 连续构造默认 Agent A、B | 同名工具对象各自独立；各自 agent 工具父指针指向自身 | `test_default_tools_and_parent_are_distinct` |
| R01-S2 | A/B 各写 Todo；reset A | A 不见 B 的清单；reset 不影响 B 清单 | `test_todo_and_reset_do_not_cross_agents` |
| R01-S3 | A 允许派生但拒绝写；B 自动允许；A 派生写任务 | 必须询问 A 的写入授权；目标不存在；B 模型不被消费 | `test_child_uses_own_parents_model_and_denial` |
| R01-S4 | 子 Agent 写自己的 Todo | 父 Todo 保留，子任务清单不能替换父清单 | `test_child_todo_does_not_replace_parent_todo` |

`SessionState` 的可变集合必须使用 default_factory。仅复制 ALL_TOOLS 列表不满足 S1；仅禁止写入而未确认授权来自 A 不满足 S3。LLM/permission/hooks 的父子共享是显式能力继承，不允许从全局最近创建的 Agent 获取。

失败边界：已有所有者的 AgentTool 传入另一 Agent 时 MUST 拒绝重新绑定；自定义有状态工具无法 clone 时 MUST 清晰报错，不能默默共享。

后续验证（本次代码未覆盖）：反向授权组合、自定义工具重绑定、多线程创建、child checkpoint 分组归属。
