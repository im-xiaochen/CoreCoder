# R02 关键 spec：统一 cwd

状态：待实现。设计：[R02](../R02_workspace_paths.md)。测试：[test_r02](../tests/test_r02_workspace_paths.py)。依赖 R01；接口见 [公共契约 §1](../CONTRACTS.md)。

| ID | Given / When | MUST / Then | 对应测试函数 |
|---|---|---|---|
| R02-S1 | 根/sub 有不同内容的同名 marker；shell cd sub | read 读 SUB；write/edit 落在 sub；glob/grep 返回 sub 绝对路径；提示显示 sub；进程 cwd 不变 | `test_cd_then_all_file_tools_share_cwd`（普通及中文空格目录） |
| R02-S2 | 同一 batch 先 cd 再 write 相对路径 | 后者使用更新后的 cwd，根目录不出现目标文件 | `test_same_batch_cd_then_write_is_ordered` |
| R02-S3 | 父 cwd=work；子读取、cd nested 并写入 | 子起点为 work，写入 nested，父 cwd 仍为 work | `test_child_starts_here_and_cannot_change_parent_cwd` |
| R02-S4 | cd 不存在目录；随后使用绝对文件路径 | cwd 不变；绝对路径正常工作 | `test_failed_cd_and_absolute_paths` |

路径公式：`absolute = Path(value).expanduser()`；相对值必须经 `state.cwd / value` 解析。默认 path="." 也遵循同一规则。所有 mutating/unknown 调用作为串行屏障，不能把写入和依赖测试当作独立读取并行。

复杂 shell cd 不在首版解析覆盖范围时 MUST 显示目录未跟踪；不得猜出错误 cwd。Windows 命令转义由 shell 路由层处理，state 存 native 绝对 Path。

后续验证：Linux/macOS、条件/函数/变量间接 cd、跨盘路径、父子并发、只读并行与副作用屏障交错。
