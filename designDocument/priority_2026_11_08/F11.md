# F11 按需技能

技能目录固定为可信工作区根下 .corecoder/skills/<name>/。提供三个随包模板 review、test、pr-summary。每个模板只有文本，审阅、测试、PR 摘要经正常 Agent 流程和权限门禁运行。来源展示 builtin 或项目相对路径、版本（缺少显式版本时用正文摘要标识）、实际载入文件与截断情况。内置模板资源应随 wheel 可用。

- /skills 列可调用名、来源和冲突；只枚举有界目录和文件名，正文及辅助资料仅在用户显式 /<name> [任务] 时读取。元数据可用少量可选前导字段，纯 Markdown 有默认值。提供项目技能创建示例和不合法消息。内置 slash 命令优先；项目与内置技能重名时列冲突且拒绝隐式覆盖，可使用清晰的显式选择或改名。跨平台名称规范化（小写 ASCII、连字符），重复及非法名称可见。
- SKILL.md 用有界 UTF-8 读取。辅助资料仅限技能内显式列出的相对文件，一次一层，拒绝绝对/..、越界、链接/junction、凭证、二进制、递归引用。建议每技能最多 8 个辅助文件、正文和资料合计 32 KiB；超限拒绝或截断并列明文件。该上限与现有消息预算共同生效。
- 提供共享 list/resolve 接口，CLI 与 Web 使用同一次调用快照。Web 接入既有创建 run 和审核流程；读取失败先报告，不发出模型请求。提示带来源、原任务与文本边界，视为本轮用户提供的项目资料。避免修改持久系统提示或跨轮反复注入。chat 模式先判模式再做项目 IO；plan 沿用只读能力，技能无权自行追加工具、批准命令、注册 hooks/MCP 或修改项目规则。
- 验收比较实际送模消息和 tool schema，正常/未调用、路径重定向、超预算、编码错误、缺文件、命名冲突分别覆盖；脚本内容只作为文本读取。重新调用能反映当前文件版本。
