# F09 大仓库检索与轻量地图

继续注册 grep(pattern,path,include) 和 glob(pattern,path)，末尾增加可选 offset、limit，返回既有文本格式。新增只读 repo_map(path=".",query="",offset=0,limit=...)。核心、Web workspace 工具及子 Agent 共用检索逻辑，工具集合沿用当前模式，chat 不访问文件。地图显示相对路径、行号、目录摘要和 Python 函数、类、导入；其他语言先提供目录/文件定位。无需常驻索引。

1. 枚举优先使用 rg --files -0 --no-config。Git 仓库缺 rg 时可使用 git ls-files -z --cached --others --exclude-standard，过滤已删除文件；无两者时有界目录遍历，说明支持的 ignore 子集，不能将已忽略的私密内容带进结果。保留原排除目录，处理嵌套 ignore、否定模式、特殊文件名。任何后端均拒绝 .git、工作区凭证路径、越界路径及重定向链接；单文件直接传入同样过滤。工具不执行仓库脚本。
2. grep 保留已支持的 Python 正则语义；可用 rg 枚举并由受限扫描器匹配。检查二进制、文件大小、扫描总量、最大返回字节与行宽；对子进程限制输出、超时、清理。避免无界列表和无界正则运行；超限明确给出原因。默认保持 grep 200 / glob 100 的输出量级。offset >= 0，limit 有正上界，建议至多 200，非法值返回工具错误。
3. 分页按确定性顺序，沿用 glob 的最近修改优先时须增加相对路径作为平手规则；相同文件中按行号。页末告知下一 offset，已耗尽扫描预算则说明可能不完整。路径/行号是证据，重新调用反映磁盘现状。文档说明翻页间文件变化会影响页边界。
4. 在同一固定仓库对照旧版与新版定位跨文件引用，记录扫描时间、返回字符数/近似 token、查询路径和发现结果；不同大小写平台规范化比较。验收覆盖 ignore/重定向/超大/无 rg、两页无重复、修改后重扫、CLI/Web 真工具入口及 chat 零自动访问。
