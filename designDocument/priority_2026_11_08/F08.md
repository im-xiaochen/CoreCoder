# F08 每次运行的模型预算

一个顶层任务使用一个控制器，子 Agent、上下文摘要、工具驱动的后续模型轮次共享。默认全部上限为空，旧会话与默认客户端行为保持。配置 requests、total_tokens（非负整数，零即禁止）、cost（非负十进制定点字符串），未知价策略默认 deny_when_capped；仅显式允许时使用 allow_unknown 并展示未知笔数及不确定金额。CLI 与 Web 提供配置及可读剩余量，Web 启动前冻结本 run 的限制。使用 run 历史记录最终摘要，旧 run 无数据表示不可用。

## 状态与计量

reserve(attempt_id, request, rates) → reservation；settle(attempt_id, usage_or_unknown) 幂等。只对即将实际发出的 provider 请求计次，锁内原子比较已计量、未确认及未完成的预留；锁外进行网络和回调。请求计数涵盖 OpenAI、LiteLLM、创建时重试、400 参数回退、中途断流重试、摘要与子任务。严格预算下关闭 SDK、适配层隐含的额外自动重试，让每个物理尝试经过同一门禁。传给 provider 的输出上限不高于预留、模型与上下文允许值（兼容两种参数名）。输入估算包含最终系统提示、消息、工具定义、规则和本轮技能。

F01账本仍是已知用量的真值；按唯一尝试 ID 对账。已知 usage 按实际替换预留，绝不把估计伪装为实付。失败/断流/取消已发请求且缺少 usage 时保留不确定额度，限制后续尝试。未发出可证明时释放预留。无价格且无费用上限仍执行；有费用上限默认在发送前拒绝，显式放行时保留未知状态。供应商报告超出估计时保存超额，阻止后续请求。显示请求已发/剩余，token 与费用分别列出已知实际、在途预留及未确认预留；对已知费率用请求时快照，不因后来切模型或改配置重算。

## 中止及验证

达到上限产生可识别 budget_exceeded 原因，沿既有终态协议返回；不得当作可重试 provider 错误，也不得被摘要降级、子 Agent 包装为成功后继续发请求。中止保留已完成工作和账本。并行请求同时要最后一份额度时只允许一方预留。重连读取报告不重发任务；重启中断原 run，未完成预留呈现为未知，禁止重复执行。缺少底层计量适配的客户端在启用预算时显式拒绝，不静默绕过限制。

独立验收用 fake transport 实际统计发出尝试，覆盖零和临界上限、重试/400/中途断流、跨子任务与摘要、并发预留、Decimal费率、未知价格两策略、异常/取消不重复结算、老数据及前端剩余量。说明输入 token 为估算，最终账单受供应商计量影响。
